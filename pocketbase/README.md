# Playwright Training with PocketBase

This project demonstrates end-to-end testing of a PocketBase application using Playwright.

## Prerequisites

- Node.js (v16 or higher)
- PocketBase (download from [pocketbase.io](https://pocketbase.io))

## Setup

1. Clone this repository.
2. Install dependencies: `npm install`
3. Start PocketBase: `pocketbase serve`
4. Run tests: `npx playwright test`

## Project Structure

- `tests/`: Playwright test files
- `pocketbase/`: PocketBase configuration and data

For more details, refer to the [Playwright documentation](https://playwright.dev) and [PocketBase docs](https://pocketbase.io/docs).
